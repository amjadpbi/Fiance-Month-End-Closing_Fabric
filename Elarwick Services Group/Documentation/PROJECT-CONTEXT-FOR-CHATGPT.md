## 1. What this project is

A study library for a 9-class online course series called "Learn AI with Hisham",
taught by Hisham Sarwar, in Urdu with English technical terms.

For each class, the library contains:
- 4 handwritten-style notebook pages (images)
- Short key points in plain text
- A short Urdu description, with class date and topic, no emoji
- A link to the original class video on Facebook
- A full, auto-generated transcript as a downloadable .md file,
  split into 5-minute timestamped blocks

The notes are important-points summaries of the main workflow.
They are NOT a verbatim transcript, and NOT a click-by-click manual.
The transcript files are auto-generated, unedited, and may read roughly
in live parts of the class.

Total scope:
- 9 classes, 12 to 26 Oct 2026
- 19 hours 15 minutes of class video in total
- 36 notebook pages (4 per class)
- 9 transcript .md files

## 3. Notebook pages visual style (already done, do not redo)

Style name: NBLM / Notebook LM style.
- A real ruled or grid notebook page
- Script handwriting font, large cursive headings
- Yellow, pink, green and purple highlighter strokes
- Boxes, arrows, small flow diagrams and doodles
- Short bullets, and a Key Takeaways / Key Takeaway box
- Not long paragraphs

Visual variation rule, from Class 04 onward:
Keep the core NBLM style, but vary per class so classes are
distinguishable at a glance: a different dominant accent colour,
topic-matched doodles, and a coloured class-number tab.
Examples already used:
- Class 04: grid paper, teal and orange, database and server doodles
- Class 05: purple and pink, microphone and phone doodles
- Class 06: green and gold, magnifier and chart doodles
- Class 07: sky blue and yellow, calendar and camera doodles
- Class 08: crimson red and gold, social and calendar doodles
- Class 09: original NBLM style, before the variation rule

Classes 01 to 03 and 09 are NOT to be redone unless the owner asks.

## 7. Research: relevant platforms for inspiration

### Udemy / Coursera / Teachable — the course player model
- Distraction-free main content area
- Expandable curriculum sidebar
- Progress checkmarks, percentage completion, progress bar
- Primary actions: Next Lesson, Mark as Complete
- Coursera: clean, structured, progress tracking keeps learning organised
- Udemy: clean player, easy lesson layouts, lifetime access feel
- Strength: fits this project perfectly (9 lessons, notes, video, transcript)
- Weakness: clean, not colourful

### Duolingo — the colourful, gamified model
- Bright colours, fun animations, bite-sized lessons
- Streaks, badges, XP, levels, daily goals, progress bars
- Learning feels like a game, not studying
- Strength: the colour and motivation the owner wants
- Weakness: full gamification can feel too childish for adult business
  learners, and this course has no quiz / XP system to reward

### Tutor LMS 4.0 — the middle model
- Offers Modern, Kids and Legacy modes from one setting
- Kids Mode: jolly, colourful, playful icons
- Modern Mode: clean dashboard for adult learners, unified progress tracking
- Lesson: colour and adult professionalism can live together if colour
  is used for navigation, progress and lesson identity, not decoration everywhere

### Khan Academy — mastery model
- Skill tree, badges for subject complexity, progress board, points
- Mastery targets and achievement badges after concrete milestones

## 8. Recommended direction (not yet chosen by the owner)

Hybrid, unless the owner picks otherwise:
- Udemy player structure: sidebar curriculum, main lesson viewer,
  Next Lesson / Mark as Complete
- PLUS Duolingo-style colour and progress: a colourful lesson path,
  a bright progress indicator, lesson badges, and a completed count
- Keep an adult, business tone, like Tutor LMS Modern Mode

In practice, that means:
- A vertical, colourful learning path, not a grid of cards
- Each lesson as a big, coloured step the user taps to open
- A dashboard showing lessons completed, pages viewed, and next lesson,
  not just a percentage
- A notebook viewer inside the lesson, with swipe / arrow navigation,
  not a long scroll of all pages
- Mobile-first, fast, no external dependencies that break offline use
- Progress saved in the browser (localStorage is acceptable for a static page)
